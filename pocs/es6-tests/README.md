# ES6 Tests

A React POC to practice and review ES6+ concepts through small, isolated components.

## Concepts covered

| Component           | Concept                                           |
| ------------------- | ------------------------------------------------- | --- | -------------------- |
| `ArrowFunctions`    | Arrow function syntax `() => {}`                  |
| `Destructuring`     | Object destructuring in props `{ name }`          |
| `SpreadOperator`    | Spread props onto a component `{...props}`        |
| `TemplateLiterals`  | Template strings with `${}` interpolation         |
| `DefaultParameters` | Function parameters with default values           |
| `ArrayMethods`      | Array `.map()` for transforming data              |
| `Promises`          | Creating and resolving a `Promise` with `.then()` |
| `ShortCircuit`      | Conditional rendering with `&&`, `                |     | `, and ternary `? :` |

## Running

```bash
yarn install
yarn dev
```
